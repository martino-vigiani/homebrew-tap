# martino-vigiani/tap

Homebrew formulae that install a prebuilt binary. No compiler, no language
toolchain — just the file.

```sh
brew install martino-vigiani/tap/tiny
```

| Formula | What you get |
|---|---|
| [`tiny`](https://github.com/martino-vigiani/tiny) | Declarative terminal wizard. YAML in, JSON out. ~3 MB. |
